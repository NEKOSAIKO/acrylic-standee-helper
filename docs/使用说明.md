# 亚克力立牌助手 0.2.7

本次将导出按钮、文件菜单和教程中的名称统一为“生成 .ai 文件”。应用名仍为“亚克力立牌助手 0.2”，界面版本标记为 0.2.7。

## 打开新版

先关闭旧版窗口，解压新包，双击“亚克力立牌助手 0.2.app”。适用于 Apple Silicon Mac、macOS 14+。AI 导出连接本机 Adobe Illustrator。

## 高亮操作引导

打开引导后，主界面整体变暗，当前按钮或参数保留亮度，并用边框高亮。说明卡片放在旁边，以连线指向控件。

八个步骤依次介绍：导入图片、主体尺寸与透明边、白墨画笔、底座、插脚参考、高级设置、工厂备注和导出。引导自动切换到相应页面，并滚动到目标参数。

高亮控件可以直接操作；其余区域暂时遮挡，避免误点。点击“上一步”“下一步”浏览，点击“结束引导”或按 Esc 退出。需要在整个画布上补画时，可先结束引导。

退出后会恢复进入引导前的查看页面和预览模式，不会重置制版参数；引导中主动修改的数值仍保留。

升级后首次打开会展示新版引导。完成或退出后，下次启动不再自动显示；右上角“使用教程”或“帮助 → 使用教程”可随时重看。

## 高级设置

右侧分页下方增加“高级设置”复选框，首次默认收起。勾选后，当前页面会显示精细参数；展开状态会记住。

| 页面 | 收入高级设置的项目 |
| --- | --- |
| 刀线 | 凹角圆滑半径、跨接开口上限、凹口深度阈值 |
| 白墨 | 透明度模式、白墨内缩、矢量实白、图案透明度阈值 |
| 底座 | 单/双插脚、参考框向上延展、插槽尺寸修正 |
| 交付 | 分辨率参考值 |

常用的主体尺寸、透明边、平滑、自动跨接和刀具直径、补白画笔、底座尺寸及导出仍直接可用。收起高级设置保留已调整的参数，不会撤销修改；需要还原参数时请用“恢复默认设置”。

## 应用图标

紫色底色上的透明亚克力立牌与底座，已打包为 macOS 多尺寸应用图标，同时用于主界面。图标原图及生成提示词另存于“亚克力立牌助手_应用图标.png”和“亚克力立牌助手_图标制作说明.md”。

## 跟随系统外观

无需在应用内选择主题。应用自动跟随 macOS 的浅色、深色或自动外观；系统切换时，已打开的窗口会同步更新，不必重启。切换外观会保留当前参数、补白笔迹、缩放和画布位置。

窗口、参数侧栏、画布、文字与透明格子均适配深色模式。黑色仍表示白墨覆盖区域。主题仅改变屏幕预览，不会将深色背景带入生产图稿。

## 预览按钮与毫米单位

“适合画布”“实际尺寸”“像素细节”位于左侧主画布区域的右下角，状态信息保留在左侧。“下一处”和局部跨接按钮仍在预览上方。

新导出的 AI 文档默认使用毫米，保存后再次打开保留该单位。该设置不改变主体、插脚参考框或底座的物理尺寸，也不更改已有 AI 文件的单位。

## 插脚参考框

在“底座”页勾选“高级设置”，调整“参考框向上延展”，默认 3 mm。参考框顶部按插脚整个宽度内的主体下沿定位，再向上留出所设余量，避免只覆盖较低部分留下缺口。可继续调整插脚位置、宽度和数量。

插脚仍是独立图层内的空心矩形，只标识位置，由工厂调整。底座外形和插槽生成方式不变，参考框底部和插入深度不因向上延展而改变。

## 恢复默认设置

右侧分页下方有“恢复默认设置”按钮，一次恢复尺寸、透明边、平滑、白墨、底座和画笔大小等参数。保留当前原图、项目名称、备注和手动补白；局部跨接选择恢复默认。

点击“撤销操作”或按 ⌘Z，可以撤销这次重置。

## 手动补白

1. 打开“白墨”页，勾选“启用补白画笔”，自动切换到白墨视图。
2. 调整“画笔直径”，默认 2 mm。点击补一处，按住鼠标拖动可连续涂抹。黑色表示要印白墨的区域，淡彩图只用于辅助定位。
3. 滚轮缩放；按住 Option 拖动画布。关闭画笔后恢复普通拖动。
4. “撤销上一笔”移除最后一笔；“清空手动补白”还原自动白墨。两者也可通过“撤销操作”或 ⌘Z 撤销。

补白直接合入原分辨率白墨，能够补透明小孔与局部缺墨，不修改彩色原图。画笔仅作用于原图画布和主体刀线以内，不影响底座。笔迹跟随原图像素定位，缩放预览、移动画布或调整成品尺寸后不会错位。

补白在白墨内缩等自动处理之后合入，手动补过的位置会重新铺满。更改自动白墨参数时保留笔迹；清空手动补白后恢复当前参数对应的自动白墨。

补白记录属于当前图片会话，重新导入图片会清除笔迹和旧撤销记录。关闭应用前请导出 AI/PDF 保存结果；本版尚无项目保存/恢复功能。

## 导出

手动补白会进入 AI 的“02 白墨 K100”图层和 PDF 第 2 页；矢量实白模式也包含补白。工厂说明中标明手动补白笔数。白墨图层默认隐藏，可在 Illustrator 中打开。

AI 为两个画板，图层包括彩图、白墨、主体刀线、插脚位置参考、底座与插槽、制版说明。PDF 共六页，分别为总览、白墨、主体刀线、底座与插槽、插脚参考、说明。白墨仍为 CMYK K100，彩稿仍保留原像素。已有同名 AI/PDF 不会被覆盖。
